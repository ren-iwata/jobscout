# 00_vision — JobScout（プラットフォーム案件獲得エージェント）

企画受領: 2026-07-19（CEO投入・ChatGPT会話の抜粋。整形と設計は開発部CTOに委任）。案件#004(仮)。

## 一言定義
Upwork・クラウドワークス上の案件を分析し、利用者の能力・実績・戦略に照らして応募判断・提案文・見積もり・確認事項を生成し、応募結果から学習するフリーランサー向けエージェント。利用者は受注したい側（最初の利用者はCEO自身）。

## 本質
応募文生成AIではなく「案件選別・受注戦略・提案形成・結果学習を一体化した意思決定エージェント」。AgentFront（待ちの受注装置）と対になる「攻めの受注装置」であり、旗（受注向け実績蓄積）に直結する。

## 重要な制約（設計の根幹）
自動応募ボットにしない。自動ログイン・スクレイピング・自動巡回・自動応募・自動メッセージは行わない（Upwork規約・アカウント保護・全社規範）。初期形は「人間が案件文を貼り付け、AIが分析し、人間が最終応募する」。これは弱い設計ではなく、応募品質とアカウント安全性を両立する設計である。

## 価値仮説
「自分の市場価値は低いのか、まだ測定されていないだけなのか」を応募実データで検証する装置になる。
